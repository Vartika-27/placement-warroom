# Folder Structure Documentation

# Introduction

This document explains the folder organization and structural architecture of the Placement War-Room frontend application.

The folder structure is designed to:

* improve maintainability
* support scalability
* separate concerns clearly
* simplify future feature expansion

The project currently follows a modular frontend structure using React.

---

# Root Structure

```txt
placement-warroom/
│
├── docs/
├── public/
├── src/
├── package.json
├── vite.config.js
├── README.md
└── node_modules/
```

---

# src/ Internal Structure

```txt
src/
│
├── components/
├── pages/
├── App.jsx

└── index.css
```

---

# 4. src/components/

## Purpose

Contains reusable UI components.

## Why Components Exist

React applications are built using reusable UI modules.

Instead of rewriting UI repeatedly, components allow:

* modular design
* reusability
* cleaner code organization
* scalable frontend systems

## Current Components

### Navbar.jsx

Handles application navigation.

### StatsCard.jsx

Displays dashboard statistics.

### GoalCard.jsx

Displays individual goals and goal actions.

### TeamMember.jsx

Displays leaderboard user information.

## Benefits of Component-Based Architecture

* code reuse
* easier debugging
* isolated UI logic
* maintainable structure

---

# 5. src/pages/

## Purpose

Contains page-level components.

## Difference Between Pages and Components

### Components

Reusable smaller UI elements.

### Pages

Large route-level application sections.

## Current Pages

### Dashboard.jsx

Main productivity dashboard.

### Team.jsx

Displays accountability leaderboard.

### Profile.jsx

Displays user profile information.

### Login.jsx

Authentication interface.

## Why Page Separation Matters

Separating pages:

* improves readability
* simplifies routing
* supports application scaling
* reduces App.jsx complexity

---

# 6. App.jsx

## Purpose

Acts as the central application controller.

## Responsibilities

App.jsx currently handles:

* routing setup
* global state management
* application layout
* page rendering
* goal management logic

## Why It Is Important

App.jsx acts as the root component of the frontend application.

It coordinates:

* state flow
* routing systems
* component rendering

---

# 7. main.jsx

## Purpose

Application entry point.

## Responsibilities

main.jsx:

* connects React to the browser DOM
* renders the App component
* imports global styles

## Important Concepts

### createRoot()

Used to initialize React rendering.

### StrictMode

Used for highlighting development issues.

---

# 8. index.css

## Purpose

Global stylesheet configuration.

## Current Usage

Currently used for:

* Tailwind CSS import
* global application styling support

---

# 9. node_modules/

## Purpose

Contains installed project dependencies.

## Important Note

This folder is automatically generated by npm.

It should:

* never be edited manually
* never be uploaded unnecessarily

# File Organization Philosophy

The project follows these organizational principles:

## 1. Separation of Concerns

Each folder has a clearly defined responsibility.

## 2. Modularity

UI elements are separated into reusable modules.

## 3. Scalability

The structure supports future growth.

## 4. Maintainability

Organized code reduces debugging difficulty.
